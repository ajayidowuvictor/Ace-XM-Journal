# Architecture

## Layers

1. `app/`: screens and routes only (Expo Router).
2. `src/ui/`: design tokens and reusable components.
3. `src/features/<feature>/`: components, hooks and logic per feature.
4. `src/db/`: SQLite via expo-sqlite, numbered migrations, repository functions. The only code that writes SQL.
5. `src/lib/`: date and time-zone helpers, streak and review calculations, export.

## Data model (local first)

tasks, categories, journal_entries, tags, entry_tags, mood_records, habits, habit_completions, goals, milestones, task_goal_links, reviews, settings.
Every row has a UUID, `created_at`, `updated_at` and `deleted_at`, so cloud sync can be added later without a rewrite.

## Dates

Day-based records store a local calendar date string (`YYYY-MM-DD`). Moments store UTC timestamps. This avoids time-zone and date-boundary bugs in habits and the calendar.

## Privacy and security

Local-only first release. Journal database encrypted on the device. No secrets in the repository; only public keys in the app. If cloud sync is added (Phase 7): Supabase Auth and row-level security on every table.

## Journal encryption

Journal entries live in their own database, `journal.db`, encrypted with SQLCipher (`useSQLCipher` in the expo-sqlite config plugin). On first use the app creates a random 256-bit key and stores it with expo-secure-store; the database is unlocked with `PRAGMA key = "x'<hex>'"` right after opening. A wrong or missing key produces an error screen; the journal is never deleted or recreated automatically. Android auto-backup is off (`android.allowBackup: false`). Deleting an entry erases its title, text, mood and tags and keeps an empty marker with the deletion time. Tasks stay in the separate, unencrypted `acexm.db`.

## Theme and small preferences

One theme in `src/theme/` supplies colours from `src/ui/tokens.ts`. The user's choice (system, light, dark), the first-run flag and the display name are small settings saved with `expo-sqlite/kv-store` (`src/lib/preferences.ts`). The main journal and task data will use the SQLite database in `src/db/` (Phase 3 onward).

## Navigation

Expo Router with native tabs (`expo-router/unstable-native-tabs`, the SDK 57 path). The root layout shows onboarding until it is completed, then the tabs, using `Stack.Protected`.
